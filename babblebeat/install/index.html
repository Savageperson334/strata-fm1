BabbleBeat is an emulator-only preview

Not yet released for hardware.

The speech and grammar code passed host simulation, but it hasn't been tested on a physical M-VAVE FM-1. There is no BabbleBeat firmware file to install at this stage.

Play BabbleBeat in the browser or read the manual.

STRATA and PALINDROME have their own separate install pages. Switching instruments installs a separate firmware; BabbleBeat is not an additional mode inside them.
