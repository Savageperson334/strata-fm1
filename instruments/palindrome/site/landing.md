# PALINDROME

**SILT is the instrument. MORPH is the injector.** Three audio rings can play independently, combine, and become the source of the next generation.

![PALINDROME's circular SILT display](manual/img/silt.png "SILT — three concentric recordings")

## Play, scan, print

- **PLAY:** start gently drifting playback without rewriting a recording.
- **KNOB1 / SCAN:** browse the recording directly; **KNOB2 / GRAIN** shapes fragment length.
- **KNOB3 / FLOW:** increase or decrease how the playback head wanders.
- **KNOB4 / WEAVE:** 0 = one ring; halfway = two; full = all three.
- **REC:** print the processed sound to a new ring—solo for passing forward, or blended for printing all at once.
- **SELECT:** change which ring you edit. **GLO:** toggle Help with one tap.
