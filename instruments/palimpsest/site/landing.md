# PALIMPSEST

MORPH generates audio with four synthesis methods. SILT captures, fragments and resamples that sound. Change modes without interrupting either engine.

- [Play the browser emulator](emu/).
- [Install PALIMPSEST](install/) on an FM-1 (custom firmware, at your own risk).

Version {{VERSION}}. [Download firmware](firmware/{{PKG}}).

Built on fm1-base, MPL-2.0. The audio memory is volatile; test the browser before flashing.
