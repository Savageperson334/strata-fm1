# STRABBLEDROME

**STRATA, PALINDROME and BabbleBeat in one firmware, behind one menu: one install for all three.** Press GLO, turn SELECT, press SEL. One instrument runs at a time, and each plays exactly as it does by itself.

![The menu](manual/img/menu.png "The menu · GLO")

## Switching

- **GLO** opens the menu, from anywhere.
- **SELECT** chooses; **SEL** opens it. The instrument starts afresh.
- **GLO** or **HOME** goes back without changing anything.
- **HELP / CONTROLS** in the menu shows the running instrument's own button guide.
